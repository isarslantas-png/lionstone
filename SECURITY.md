# Security

Lionstone processes untrusted media files with FFmpeg. Keep FFmpeg up to date — most media parser vulnerabilities are fixed there.

Please report vulnerabilities privately through GitHub's **"Report a vulnerability"** (Security tab) rather than a public issue. You'll get a response within 7 days.

Lionstone never uploads media or telemetry. Network access happens only when downloading ASR models or, if you opt in, when calling an LLM API with your own key.
